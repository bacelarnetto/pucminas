# Módulo de Moradores
Módulo Mobile de cadastro utilizado pelos próprios moradores para visualizar as informações das barragens próximas das suas residências e receberem alertas.<br/>

## Instalação
`yarn` <br/>



## Principais bibliotecas e frameworks usados.

- React <br/>
     URL: https://reactjs.org/<br/>

- React-router <br/>
     URL: https://reacttraining.com/react-router/<br/>

- Reactnative <br/>
     URL: https://reactnative.dev/<br/>
     
- Axios <br/>
     Cliente HTTP baseado em promise<br/>

- OneSignal<br/>
     URL: https://onesignal.com/<br/>

- Socket.io<br/>
     URL: https://socket.io/<br/>
